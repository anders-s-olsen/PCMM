# Validation status

Revised 28 September 2026 for the shared-label product-mixture design.

**The full default scientific experiment has not been run.** No likelihood,
NMI, selected K, convergence claim, noise effect, or model ranking should be
inferred from this repository state. In particular, the implementation does
not tune the noise level or any model to make one family outperform another.

## What the revised validation must establish

Before treating an output as a scientific result, the preparation report and
tests must establish all of the following:

- Exactly three distinct MiniLibriMix speakers occupy measured mouth positions
  1, 2, and 3. Display candidates are 1, 2, 3, and the empty seat 5.
- Exactly four measured microphone channels are used: native one-based IDs 1,
  4, 5, and 7. Microphone and mouth-position coordinates remain distinct.
- Train and held-out utterance IDs do not intersect within a speaker, and no
  speech recording is duplicated between speakers or splits.
- Every final train and held-out STFT frame has at least one active speaker.
  Exactly-two-speaker frames target 8% and never exceed 10%; exactly-three-
  speaker frames target 2% and never exceed 5%. Default target tolerance is
  1.5 percentage points.
- Source airtimes are approximately balanced. Array-received powers of the
  isolated training source images are balanced by training-derived gains, and
  exactly those gains are reused for held-out data and both conditions.
- `no_driving_noise` and `car_noise` contain bit-identical rendered speech
  scenes before noise addition: the same samples, schedules, impulse responses,
  source gains, STFT grid, and source-reference energies.
- Measured driving noise retains its multichannel structure. Training and test
  use disjoint noise material, and a gain calibrated on training at the
  configured SNR is frozen for test.
- Fitting and held-out scoring use every frame in both conditions. The saved
  speech mask and validity masks are all true; no amplitude gating or oracle
  activity filtering changes the model observations.
- K is the total unconstrained component count. No component is preassigned to
  background or to an occupied seat.
- Work is scheduled in K/model/condition order, with deterministic paired
  restart seeds across the two conditions. Restart choice, initial frequency
  matching, consensus labels, and all component refits use training data only.
- The `uniform_vmvm` family invokes PCMM's uniform-marginal VMVM with
  `oscillatory_data=True` for fitting and frozen evaluation, using all four raw
  phase coordinates. The former quotient wrapped-normal family is absent.
- Posterior rows have shape `(K,n)`, sum to one, and retain their fitted order.
  Per-frequency log densities and joint multfrequency frame densities are
  finite and normalized in the correct family sample space. Final component
  row k is refit on the same shared training-frame partition at every frequency.
- Each completed `(K, model, condition)` record atomically refreshes both
  condition-specific 1-by-2 performance PNGs. Likelihood curves are centered
  at that family's K=1 value and are not compared across sample spaces.
- K=3 car atlases use exported consensus-refit parameters evaluated against
  steering templates at seats 1, 2, 3, and 5 and pooled across frequencies.
  The plotted contours are clearly labelled as schematic interpolation, not a
  physical covariance or calibrated location posterior.

## Required run-level checks

A bounded integration run should precede the full job. It should exercise both
conditions, all five families, at least two selected frequencies, K=3, one
restart, and a deliberately small iteration limit. That run is plumbing only:
its fitted metrics must not be reported as scientific results. Inspect that it
produces finite posteriors and likelihoods, paired observation counts, learned
parameter exports, four-seat steering scores, and readable partial/final PNGs.

The full job must then be allowed to reach the `results.json` completion marker.
For every family/K/condition, inspect failed restarts and consensus diagnostics
rather than assuming a saved file implies a good optimum. Confirm that
the number of metric rows equals:

```text
number of K values × number of model families × 2 conditions
```

Also compare the saved preparation ID in every result against the current
prepared metadata, and verify that the two performance plots and two K=3 atlases
were regenerated by that run.

## Interpretation checks

The primary NMI assigns one dominant speaker to each time frame. It does not
measure recovery of all simultaneously active talkers, so inspect the saved
single-talker and overlap-stratified summaries. Frames overlap in the STFT and
are not independent experimental replications; no framewise confidence interval
should be presented as though they were.

Absolute likelihoods are incomparable across the Euclidean Gaussian,
projective directional, and toroidal VMVM sample spaces. Only within-family
changes over K are plotted. The held-out set is also used for selecting K, so
the chosen-model likelihood is a selection score rather than an untouched
final-test estimate.

K=3 need not maximize either metric. A component can represent noise, overlap,
amplitude regimes, or model mismatch rather than one physical source. Likewise,
an atlas preference for an occupied seat is supporting evidence for a spatial
interpretation, not continuous localization accuracy.

## Superseded checks

The earlier scaffold was exercised on three speakers at seats 1, 4, and 7 with
microphones 1, 4, 9, and 12, amplitude gating, no driving-noise condition, and a
quotient-phase baseline. Nine automated tests and one shortened all-family
adapter run were reported for that design on 31 August–1 September 2026. Those
checks remain useful historical evidence for shared alignment and adapter code,
but they **do not validate the revised paired experiment** and their old shape,
masking, figure, or model-family counts must not be quoted as current results.

Run the current automated suite with:

```bash
python -m unittest -v test_experiment
python -m unittest -v test_fitter_adapter
```

Record current test and bounded-integration outcomes here only after they have
actually completed. The full default scientific comparison remains pending even
if those software checks pass.
